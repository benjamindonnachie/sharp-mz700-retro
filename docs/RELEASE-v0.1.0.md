# GIDE software v0.1.0

The initial software release contains the 4 KiB GIDE boot monitor, card-resident file manager, patched BASIC, ATA/RTC diagnostic and fixed-partition CP/M 3 system.

The original release package has been withdrawn and superseded by [v0.1.1](RELEASE-v0.1.1.md), with revised documentation. Executable firmware is unchanged. The replacement card images contain an updated README and therefore have different checksums.
