Sharp MZ-700 GIDE starter image

The file manager launches compatible machine-code MZT/MZF files, CP/M
and GIDE BASIC. BASIC programmes are loaded from within BASIC using SD:.

CP/M uses fixed native C: and D: volumes. FAT32 support for CP/M is in
development; the shared FAT32 partition currently serves the PC, file
manager and BASIC.

BASIC, GAMES and PCG are supplied as empty directories for additional
software. The RAM monitor saves to SAVES. No games collection is included.
Switch off the Sharp before changing media or IDE connections.
